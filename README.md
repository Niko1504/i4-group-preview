# Khidi — прототип акселератора для Грузии (опубликован)

Аналог mostbi.com (MOST Business Intelligence, Алматы/Ташкент) для грузинского рынка.
Прототип подготовлен 04.11.2026 в рабочей группе по разбору стартапов.

## Живые ссылки
- Основная: https://khidi-lab.vercel.app
- Зеркало (открывается из РФ и СНГ): https://niko1504.github.io/khidi-preview/
- Репозиторий зеркала: https://github.com/Niko1504/khidi-preview

## Страницы
- `index.html` — главная: hero, 4 факта рынка, 8 направлений, 4 программы, воронка отбора, экосистема, форма заявки.
- `program.html` — IRA (12 недель), Pre-Flight (8 недель), Creative (6 недель), Landing (3 месяца).
- `about.html` — модель, источники выручки, принципы.
- `cases.html` — вместо кейсов публичные данные рынка со ссылками на GITA и 500 Global.
- `assets/style.css`, `assets/app.js` — стили и логика (меню, форма).
- `vercel.json` — заголовки: X-Robots-Tag noindex, X-Frame-Options DENY, CSP, nosniff.
- `robots.txt` — Disallow: /.

## Проверено на живых адресах
- HTTP 200 на всех страницах и ассетах на Vercel и GitHub Pages.
- SHA-256 `index.html` на обеих площадках совпадает: `c64a82b8…4603`.
- Доступность из РФ: узлы `ru1` и `ru2` check-host.net — HTTP 200 на обеих ссылках.
- Мобильный QA playwright: 320/375/390/768/1024/1440 px — `scrollWidth == clientWidth`, переполнения нет.
- Форма: валидация обязательных полей, сохранение в localStorage (последние 5), кнопка очистки, ветка «хранилище заблокировано»; ошибок в консоли нет.

## Ограничения прототипа (сказано на самом сайте)
- Домен не зарегистрирован, почта и Telegram акселератора не созданы.
- Форма не отправляет заявку на сервер: текст формируется и сохраняется в браузере.
- Цифры либо с пометкой «план», либо со ссылкой на первоисточник.
